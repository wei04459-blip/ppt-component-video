## 换一份新课件

在引擎目录执行：

```sh
uv run python main.py template-run --ppt '/路径/新课件.pptx' --out '/路径/笔记输出' --templates 07,08,10,12 --title '护理PPT，这框架我服了！'
```

省略模板编号默认调用06—16共11款已有模板，排除pending_user_review的17号；17号可显式指定用于测试。ready仅表示可渲染。上面命令按页序排图，正文和话题留空，是自动出图草稿。模板不会分析新课件内容，也不会自动写出11条差异化文案。

需要完整笔记时，先视觉阅读真实渲染页，填写选页、标题、话题清单（正文默认空），再调用：

```sh
uv run python main.py template-run --ppt '/路径/新课件.pptx' --plan templates/内容规划示例.json --out '/路径/笔记输出'
```

示例的文案只是占位说明，应替换为新课件真实内容。页号从1开始，标题最多20字符；首图页数按表中要求填写，引擎至少3张内容图；新完整发布包建议封面+至少4张内容图，用户已确认1+3模板保留例外。同条可按展示需要重复源页，不为凑图数制造空洞重复。

## 首图与内容图的统一规则

场景单页首图 → 内容图沿用相同场景单页；8拼首图 → 默认4张双拼内容图（显式历史规划可保留3张）；双拼首图 → 后面仍为双拼。三拼模板的内容图可采用三拼或双拼，当前15号为九拼封面、固定三拼内容图，其他原有模板中尚没有三拼首图，接入时按此规则配置。

配色、卡片、圆角、阴影、标题样式沿用首图。每张内容图是一组页号，例如 `"content_groups": [[3,4],[5,6],[7,8]]` 表示3张双拼图片，合计展示6页PPT。允许在组内或组间重复页号。旧版平铺的content_pages列表，每个页号仍代表一张输出图；双拼模板自动补入下一页，到课件末页时循环。

## 模板07固定选页规则（2026-10-09）

右侧三张大图从上到下固定为原始PPT第1、2、3页。第1页说明这是什么PPT，必须占据右上第一大图；不能因视觉选页、随机排序或去重而移走。左侧五张小图仍可按内容选择。

`cover_pages` 的顺序是左侧五张（从上到下），再右侧三张（从上到下），例如 `[4,5,6,7,8,1,2,3]`。自动出图和已有规划都会强制修正最后三个位置，并将实际页号写入执行清单。原始PPT少于3页时停止出图，不循环补页。直接调用 `render_template` 必须通过 `source_pages` 传入完整有序的原始渲染页；内容图继续使用自己的选页，不受首图规则影响。
