## 参数与调用
规划文件`模板17_示例规划.json`；页号从1开始。`title`是笔记标题（最多20字符），`display_title`是单行图片大标题。`cover_pages`固定7页，第0槽强制源第1页；`content_groups`至少3组，每组2页。所有源页完整等比置入，非16:9源保留整页并留边。

`template_options`可覆盖`header`、`title_band`、`tags`、`card_style`、`background_color`、`background_blocks`、`output_size`、`slots`；字典字段合并，数组整体替换。坐标均为1080×1440设计坐标，输出原生倍乘绘制。标签文字和框数组必须相同长度，默认4项。内容图槽位固定在库`content_layouts['2']`，封面与内页沿用同一标题带。

字体依赖引擎已有`fonts/SmileySans-Oblique.ttf`（得意黑斜体）和`fonts/NotoSansCJKsc-Regular.otf`（标签）。标题按框缩字号后填满宽度，标题须简短。

```sh
uv run python main.py template-run \
  --ppt '../outputs/两份新课件_2026-10-11/源课件/基于5E护理模式的QCC活动缩短门诊增强CT患者检查等候总时长(1).pptx' \
  --pages-dir '../outputs/两份新课件_2026-10-11/01_5E_QCC_CT等候/原始页' \
  --plan templates/模板17_示例规划.json \
  --out '../outputs/模板17_蓝色标题带七拼_2026-10-13'
```

不提供`--pages-dir`时引擎重新渲染新课件。标签、标题与页面选择须按新源内容填写；本轮只是换内容样稿。正式入库与总图库登记等待用户认可。
