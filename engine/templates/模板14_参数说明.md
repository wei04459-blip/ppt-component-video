# 模板14：护理小讲课·蓝黑柔焦双卡片

用户已确认并正式登记：14号，版本1.0，确认日期2026-10-11。

固定构图取自用户提供的参考海报。画布2160×2880，3:4；背景、文字、卡片边缘和箭头均直接按输出尺寸绘制。PPT内容使用真实源页，完整等比放入卡片，不重新生成文字、不裁剪正文。模板资产不含参考里的首都医科大学Logo、播放三角或小红书账号、文案、点赞UI。

## 调用

在引擎目录执行：

```sh
uv run python main.py template-run \
  --ppt '/绝对路径/真实课件.pptx' \
  --plan 'templates/模板14_示例规划.json' \
  --out '/绝对路径/输出目录'
```

示例规划是一份真实痤疮课件的选页示范，换课件前必须改页号与内容描述。`cover_pages`首卡优先原始第1页，第二卡选择最有代表性的关键页；`content_groups`至少3组，每组恰好两页。可加`--pages-dir '/绝对路径/真实源页目录'`复用按顺序命名的`page_001.png`等真实页图。

只试模板、没有完成内容规划时：

```sh
uv run python main.py template-run \
  --ppt '/绝对路径/真实课件.pptx' \
  --templates 14 \
  --title '护理—小讲课PPT' \
  --out '/绝对路径/排图草稿'
```

这只是按页序出图。主标题里的内容类别须与源课件相符，例如本次痤疮质量改进课件用“护理—专题汇报PPT”。

## 参数

注册配置位于`templates/library.yaml`的`'14'`。所有坐标使用1080×1440设计坐标，引擎自动按输出尺寸缩放，直接绘制到2160×2880。

|参数|固定默认值/含义|
|---|---|
|`output_size`|`[2160,2880]`，只接受3:4|
|`slots`|`[[60,245,960,542],[28,821,1024,576]]`；首卡窄、下卡宽，接近16:9|
|`card_style`|白底，圆角18，内边距7；等比contain保留整页|
|`soft_background`|黑橄榄基底＋上部蓝色柔焦光团，颜色和位置可调|
|`header`|巨大白字、黑描边、倾斜字形、深色偏移投影；单行自动适配|
|`strapline`|黄色上扬主题；正式默认放在卡片上方，避免遮PPT页头|
|`arrow`|封面保留黄底浅白描边大弯箭头，`enabled:true`、`box:[775,681,248,235]`、`protect_slides:false`|
|`content_options`|`arrow:{enabled:false}`；`slots:[[38,245,980,558],[38,830,980,558]]`，统一等宽双卡片，换新课件也自动沿用|
|`content_variants`|固定`wide_top`；三张内容图使用同一版式，不再交替内缩布局|
|`layout_variants`|统一等宽双卡片；上卡y245、下卡y830，上下x38、宽980、高558、inset7|

规划支持：

- `display_title`、`subtitle`：封面图片主标题/黄色主题，与笔记`title`分开。
- `content_display_titles`、`content_subtitles`：逐张内容图文字，数组长度必须与内容组数相等。
- `content_variants`：本模板固定使用`wide_top`，三张内容图同一版式。
- `content_options`：内容图独立视觉参数，默认无箭头且上下卡片等宽等高，左右边缘严格对齐，与封面参数分开。
- `template_options`：覆盖上述视觉配置中的`slots/header/strapline/arrow/card_style/soft_background/output_size`；字典字段合并，数组整体替换。

例如仅调整字号与箭头：

```json
{
  "template_options": {
    "header": {"font_size": 132},
    "arrow": {"enabled": true, "box": [775,681,248,235], "protect_slides": false}
  }
}
```

## 参考复刻与正式换内容

本次交付包含两种明确标记的图：参考复刻用原截图里的两块低清PPT卡片；真实课件样稿用本地真实源课件。参考复刻与真实封面保留同位大弯箭头，配置为`enabled:true`、`box:[775,681,248,235]`、`protect_slides:false`。三张内容图均取消黄色箭头，固定默认`content_options.arrow.enabled:false`，之后换课件调用也自动沿用；标题、副标题保留，内容图统一使用右图形式的等宽双卡片，左右边缘严格对齐。`protect_slides:true`仍是可选功能。

参考截图的黄字浮层在第一张卡片顶端留下重复片段，验证素材仅清理该装饰条；没有改动医疗文字。参考PPT截图、院校Logo没有进入引擎通用装饰资产。

输出分辨率不增加原始PPT中的图片细节。本次课件是整页图片型PPT，原图1672×941左右，已按幻灯片关系无损取出；最终卡片有小幅放大。源页清晰度需要更高时，应替换更高分辨率的源课件。
