## 内容与调用字段

`title`是最多20字符的笔记标题；`display_title`是图外主题；`award_label`是黄底标签；`cover_pages`填5个真实页号；`content_groups`至少3组，每组2个真实页号。

信息行仅显示真实整份课件页数，按源渲染页自动生成：`页数：{page_count}页`，在全画布宽度水平居中。本次显示“页数：15页”。不使用规划里展示的页号数量代替整份PPT页数。

本次用户已声明课件有奖项，但未给院级或具体等级，使用四字“获奖课件”，不写“院级获奖”。样稿主题为“痤疮护理专题PPT”，“护理专题”深蓝、其余黑字，符合源类别。新课件按真实类别改主题；分色可通过`template_options.header.highlights`设置，不能硬套该疾病。

`template_options`支持`header`、`info_line`、`trophy`、`card_style`、`background_color`、`output_size`、`slots`、`strapline`；不填时用固定默认。小奖杯资产独立参数`trophy.asset`，相对于模板库目录。alpha>8计算有效边界裁透明余边后contain，不拉伸。资产`assets/16-trophy.png`为built-in imagegen参考重建：金色双耳杯、无叶、无字、透明背景；提示词与制作记录见输出根“奖杯素材生成说明.md”。本模板内容图保留小杯。

封面与内容都有头部，但参考2/8的头部比封面上移22设计单位，此差异固定在`content_options`，三张内容图完全同版。专用配置复用原有award_grid绘制能力；15号仍沿用它原来的无头部三拼。

## 换真实新课件

先阅读新课件，按真实页义修改示例规划的主题、标签与选页，然后在引擎目录调用：

```sh
uv run python main.py template-run --ppt '/路径/新课件.pptx' --plan templates/模板16_示例规划.json --out '/路径/16号新课件输出'
```

已有真实源页可追加`--pages-dir '/路径/原始页'`，目录按序命名`page_001.png`等。自动排图草稿可用`--templates 16 --title '护理专题获奖课件'`；此路径仅按页序排图，不自动判断课件医学类别或奖项等级。
