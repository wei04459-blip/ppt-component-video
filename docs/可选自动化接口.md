# 可选自动化接口

无背景 Agent 制作组件视频优先使用 `../AGENT_START.md` 和 `../agent_video.py`。该入口不依赖正在运行的 GUI 服务，使用相同处理引擎，在独立工作目录中执行。

组件视频 HTTP 接口补充：`POST /api/components/analyse` 请求 `{project}`，返回所有页的 `source`、`number`、`objects`；`POST /api/components/preview` 请求 `{project,video}`，返回实际两版预览；`POST /api/video` 的 `video.mode=components` 使用 `motion`、`music`、`pages`，每页包含 `source`、`number`、`confirmed`、`components`（`id/name/text/target/before`）。矩形坐标为 0–1。HTTP 模式使用本项目的 source URL，不能把其他项目的 URL 直接粘贴进来。按页号的便携 CLI 方案格式见 `Agent视频方案格式.md`。

运行后服务仅绑定 127.0.0.1。实际地址记录在用户 Documents/鱼丸创作工具箱/running.json。

用户不需要了解这些接口即可操作 GUI。Agent 或普通脚本可调用同一套接口，不能绕过模板与输入校验。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/health | 服务标识和版本 |
| GET | /api/state | 本机项目、模板、依赖 |
| GET | /api/v7 | 完整视频模板的可编辑字段 |
| POST | /api/project | 新建或保存，字段 id（可选）、name、note、video |
| POST | /api/import | 导入：project、files（name、data；data 为 base64） |
| POST | /api/note | 图文：project、note、compress、variation |
| POST | /api/video | 视频：project、video |
| GET | /api/job/{id} | 队列/运行/完成/失败/取消状态与结果 |
| POST | /api/cancel | 请求取消：job |
| GET | /files/{relative-path} | 已保存文件，支持 Range 视频播放 |

POST 要求 Content-Type: application/json。任务返回 job，需轮询并确认 status=done，不能把提交成功视为导出成功。

推荐自动化方式：用户导出 schemaVersion=1 的方案 → Agent 修改 note/video 的内容 → 用户导入方案检查 → 界面生成。
如用户明确委托批量制作，可直接调用 /api/note 或 /api/video；每次创建隔离输出目录。不会自动发布。

note 字段：template_id、title、display_title、subtitle、cover_pages、content_groups、topics、award_label。
video 完整模板：mode=v7、topLabel、bottomLabel、color、music、texts、metrics、startMonth、scheduleRanges、images。
video 轻量模板：mode=cards、topLabel、bottomLabel、color、music、pages（title、subtitle、layout、items）。
图片替换映射为文件名到 base64。不要把未经授权的文件发送给外部服务。

## 图片处理

所有接口为本机同源 `POST /api/images/<action>`，JSON请求/响应；错误HTTP400。与现有笔记项目API独立。图片参数展开默认值可从 `defaults` 获得；只支持 `legacy_compatible`。

| action | 请求 | 响应 |
|---|---|---|
| defaults | `{}` | config、presets、warning、environment |
| import | `{session?:id,files:[{name,data:base64}]}` | session、files、added、skipped、errors |
| preview | `{session,image:id,config,generation:int}` | preview URL、generation、尺寸、pixel_sha256；旧请求可返回stale |
| export | `{session,config}` | job id；立即返回，任务配置冻结 |
| status | `{job}` | status、events、完成后result/download/directory/manifest |
| cancel | `{job}` | 协作取消确认；需继续轮询至终结 |
| presets | `{document:{preset_schema_version:1,presets:[{id,name,config}],selected_id}}` | 原子验证替换后的document |

HTTP配置/预设seed以十进制字符串传输，防JS超过2^53损失；CLI/manifest内为整数。结果URL均在现有 `/files/` 只读服务下。输入文件名清洗，不接受任意磁盘路径；只在应用数据目录写入。预览像素hash是编码前完整RGB，JPEG编码后不同属正常有损差异。每批导出都创建新目录，重名碰撞策略作用于批内及CLI指定目录。
