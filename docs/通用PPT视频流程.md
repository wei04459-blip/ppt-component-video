# 通用课件原生组件重组

入口：对比视频 → 我的PPT·手动组件重组。GUI不调用AI；Agent可协助读图、转录和设计，两者共用Motion Canvas导出。

1. 导入PPT、PDF或图片，点击“读取当前课件”。原生PPTX提取顶层对象、文字和表格作为建议，不自动理解业务含义。新读取的标题独占顶行，正文按自然网格建议摆放；已有布局不自动改动。
2. 选择1–6页，每页推荐3–8个有意义组件。图片型页面需画内容范围，再填写完整原文或基础表格。图表可重建为准确的数据表，不能把整块成品设计当照片。
3. 普通版独立制作白底黑字、基础表格；只有独立照片和标志可沿用原素材。检查数字、单位、行列和图片是否完整。修改后原确认失效，可撤销。
4. 查看真实Motion Canvas预览：普通版、重建成品和运动联系图；原课件另列仅供核对。首次每页约5–15秒，相同内容和引擎可缓存。明确具体样式差异后逐页确认。
5. 制作采用一种v7父组重组：抬升、收缩、穿行、回弹落位，组内文字不逐帧换行。外层沿用灰白折面、中文上下标签和阴影；4:3及竖页按比例放进内容槽。照片默认contain，显式cover可裁切，不拉伸。
6. 导出1080×1440、30fps、每页4秒的MP4，带AAC音轨，以及实际MC首尾图片、原生场景JSON、可编辑文字/单元格图形的普通版PPTX。PPTX单元格由矩形和文字组成，不是恢复原文件的原生表格对象。

最终是同内容的原生语义重建，不能在落位后切回原图。原始素材只读，导出按任务隔离；失败不覆盖旧成果。缺内容、字体、图片、有效帧或无效布局会报错，不回退旧截图擦除，也不补重复末帧。

sourceRef只验证方案到场景的逐段、逐单元格对应，不能证明源课件转录完整。必须读原页并核对结构编号、表格和独立照片，再看成片。不能实时播放时，应记录连续帧检查的局限，不把自动测试或联系图当作完整视觉验收。

Agent入口见AGENT_START.md，数据设计见《原生视频场景协议.md》。当前仅有Mac本地实测，Windows未实机验证。
