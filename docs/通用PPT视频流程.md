# 无需 AI 的课件组件重组（首版已实现）

入口：对比视频 → 我的 PPT · 手动组件重组（无需 AI）。

1. 导入 PPT、PDF 或图片，点击“读取当前课件”。
2. 可编辑 PPTX 提取顶层对象的边界、文本和已有分组，作为组件建议。每页最多 40 个对象，单个组件文字最多 2000 字；请人工核对是否遗漏。读取不是业务语义分析。
3. 整页图片、PDF、旧版 PPT 或读取失败的页面可以手动画框。可以勾选合并、删除重画，或输入普通版文本。组件画面使用原页截图的矩形裁剪，可能带有背景或重叠对象；不承诺透明抠图、去除截图内文字、还原遮挡背景或复杂 PPT 对象的独立矢量保真。
4. 勾选 1–6 页。按网格生成普通版，也可拖动、缩放组件。普通版有文本时用黑字白底；未填写文本时保留原图块。修改后支持撤销。
5. 查看两版实际预览，逐页勾选确认。普通版是重新排版演示，不是原作者的历史初稿；未框选的装饰会随最后的整页画面补全。
6. 选择同步平滑、错峰移动、轻抬归位。导出 1080×1440、24 帧/秒、每页 4 秒的 MP4，同时生成普通排版 PPTX、两版图片和组件方案 JSON。

原课件、旧视频和旧导出保留。替换源课件后，旧方案的页面地址不匹配会阻止导出，需重新读取。全流程不使用 AI、Agent、云模型或 API Key。

验证：两份不同真实课件的图片型页面输出 8 秒 / 192 帧视频，全片解码通过；普通 PPT 为两页、分别 5 与 4 个组件。原生 PPTX 的对象和分组提取另有测试。Mac 本地实测，Windows 已保留相同代码路径，仍待实机运行验证。
