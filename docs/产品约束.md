# 产品要求与验收约束

确认来源：用户 2026-10-17 本聊天。

1. 做笔记需要的常用功能，加上此前 v7 组件重组视频能力，封装为最小 MVP。
2. 提供用户 GUI，缩短操作步骤、降低上手门槛。
3. Mac 与 Windows 同时进入试用范围；必须分别记录真实运行证据。
4. 每项功能必须存在完整手动路径，不以 Agent 能力为必要条件。
5. Agent 为可选加速层，使用相同引擎和方案数据；人工可查看、修改并接管中间结果。
6. 不把图文、视频导出说成平台已发布，不把启动脚本说成 Windows 已验收。
7. MVP 的完整视频保留固定上方与下方组件重组，不能以整页淡入淡出替代。

本地实现：页面导入 → 模板与选页 → 文案/组件编辑 → 实际预览与导出 → 保存方案与作品。
当前交互方案为本机浏览器 GUI；原生免环境安装包、Windows 实测仍是后续发行验收。
