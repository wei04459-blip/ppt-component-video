配合Codex/WorkBuddy的新任务使用[AI视频方案协议](AI视频方案协议.md)：AI阅读真实课件并写scene与独立node.before，用户不手填。下文保留普通components兼容字段，不能据此将成品卡片拆散作普通版。

# Agent 视频方案 v1

入口见 `../AGENT_START.md`。CLI 使用页号，不使用开发机器的绝对地址或 `/files/` URL。工作目录可以整体移动后继续预览与渲染。`schemaVersion` 固定 1；`input_sha256` 必须保留 prepare 生成的值，不能改成其他 PPT 的指纹来绕过校验。

```json
{
  "schemaVersion": 1,
  "input_sha256": "保留prepare生成的值",
  "motion": "stagger",
  "music": true,
  "pages": [
    {
      "number": 2,
      "components": [
        {
          "id": "title",
          "name": "页标题",
          "text": "从原页准确读取的标题",
          "target": [0.06, 0.06, 0.88, 0.12],
          "before": [0.04, 0.04, 0.92, 0.16]
        },
        {
          "id": "chart",
          "name": "完整图表含图例",
          "text": "",
          "target": [0.08, 0.24, 0.84, 0.64],
          "before": [0.08, 0.26, 0.84, 0.66]
        }
      ]
    }
  ]
}
```

- `pages`：1–6 个不重复的实际页号。每页 2–40 个组件；推荐 3–8 个。
- `target`：原页内容来源区域及默认原生重建目标区域 `[左,上,宽,高]`，均归一化。文字和表格按此区域独立重建，只有独立照片/标志实际裁图，不是把成品裁片搬到终点。像素框 `(x,y,w,h)` 除以原图宽高得到 `[x/W,y/H,w/W,h/H]`。
- `before`：普通版中的位置与大小，同样归一化。不是绝对像素，也不是右下角坐标。
- `text`：兼容旧方案的非空原文，最多4000字；新方案优先用plain。空串不能表示复用截图。最终内容独立原生重建，源图仅供核对与提取独立照片/标志。
- `motion`：当前统一为v7父组重组。旧smooth/lift只兼容读取，不宣称提供不同动效。
- `music`：布尔值，默认 true；false 输出静音音轨。
- 外层标签固定沿用v7。普通方案可给每页design中的accent、ink、surface、line配置六位HEX色；高级scene可给各节点填写颜色与卡片样式。不要添加未实现字段并宣称生效。

该文件不是 GUI 导出方案的同一种 schema。CLI 会转换成 GUI 共用引擎接受的组件结构，最终的 `组件方案.json` 保留引擎结构；跨工作目录迁移用此处按页号的 `agent-plan.json`，不要复制旧 `/files/` 地址。

原生导出为1080×1440、30fps、每页4秒。排版只在初始化计算，整组移动；运动中不重新换行、不擦除、不替换终帧。


## 普通版必须重新制作（2026-10-25 纠正）

`target` 只定义成品端，不能用来偷代普通版。每个组件必须提供 `plain`（或兼容的非空 `text`）：

```json
{"kind":"text","text":"完整原文","role":"body"}
{"kind":"table","title":"成员信息","rows":[["姓名","人数"],["XXX","8人"]],"columns":[1,1]}
{"kind":"image","assetRole":"photo","crop":[0,0,1,1]}
{"kind":"group","parts":[{"kind":"text","text":"原文","box":[0,0,0.7,1]},{"kind":"image","assetRole":"logo","crop":[0.1,0.2,0.2,0.3],"box":[0.75,0,0.25,1]}]}
```

- 文字统一白底黑字，表格重新绘制普通网格，完整保留原文、数字与单位；纯装饰可以省去。
- `image` 只允许独立 `photo` 或 `logo`；不得把成品文字、表格、图表和整块排版标为照片。工具不能自动判断图片是否被错误标注，仍须目视检查。
- `crop` 相对该组件的原页 `target` 裁片；`box` 相对普通版组合容器，均为 `[左,上,宽,高]`。
- `group` 最多20个子项，不支持嵌套；子项可为文字、表格、独立素材。
- 每页至少包含重新制作的文字或表格。纯裁片旧方案会报错，需要重新填写内容，不能沿用旧预览。
- 最终文字和表格用原生节点，独立照片保留图片。普通版PPTX的文字和单元格图形可编辑，单元格由矩形与文字组成，不等于恢复原PPT的原生表格对象。
- 预览指纹包含语义编译器、Motion Canvas场景、v7包装、渲染入口、依赖锁和实际字体；修改后旧确认失效。

显式scene及逐段/单元格sourceRef绑定见《原生视频场景协议.md》。预览来自真实MC帧。
