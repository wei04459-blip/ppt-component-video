# MVP 0.1 本地验收记录

## 已验证

- 实际 5E/QCC PPT：15 页导入成功；模板 14 导出 1 张封面 + 4 张内容图、JPG 与文案包。
- 11 个可用模板均使用产品内的字体与素材完成测试渲染。
- 轻量卡片视频：105 帧、3.5 秒，生成与完整解码通过。
- 完整 v7：通过 GUI 点击制作，315 帧、10.5 秒、1080×1440、30 fps，H.264 + AAC。
- 完整 v7 音频非静音：mean_volume -31.3 dB，max_volume -19.3 dB。
- 抽看完整视频的三段起点、中间、终点；修正便携字体下目标达成率大数字与右侧文字的重叠。
- 4 项自动化测试通过：路径边界、输入限制、11 模板便携字体渲染、损坏导入不覆盖既有页面。
- 任务输出按唯一目录隔离，不覆盖此前模板、源课件或 v7 母片。

## 验收边界

- Windows：尚无 Windows 机器实测；提供共享代码、启动与依赖安装入口。
- 首次启动依赖安装与浏览器下载受网络影响，当前不是免环境安装器。
- GUI 为本机浏览器界面；Mac .app 是启动入口。
- 视频固定模板的内容较长时仍须预览检查；不是对任意 PPT 自动理解、抽取和排版。
- 方案文件携带参数和替换图片，不携带源 PPT 渲染页；跨电脑需重新导入对应课件。
- 当前无内置 Agent 聊天；可选加速通过方案导入与本地处理接口完成。
- 第三方背景素材沿用本地样稿用途。未宣称完成原软件 41 功能复刻或可公开售卖的发行验收。

独立产品 Python 环境复跑 4 项测试通过。接口验证任务取消、取消后重试出图、视频 Range 分段读取、跨来源写请求拦截均通过。浏览器重新加载后恢复当前作品、页号、文案与完整视频内容；导入/导出方案入口可见。

## 启动稳定性修复

发现临时会话后台退出后端口 8766 无监听。启动入口改为固定 8766，并在 Mac 使用当前登录会话的 launchd 后台服务托管；关闭启动终端不结束服务。服务配置在用户数据目录，不设置开机自动登录项。Windows 使用独立后台进程，未实机验证。启动完成前检查健康接口；重复启动复用服务。
