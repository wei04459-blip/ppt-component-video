# 参考版本说明

本目录reference.mp4和reference-preview.png现由当前Motion Canvas原生引擎实际生成。8秒、240帧、1080×1440、30fps，带AAC音轨。输入为虚构示例课件.pptx，方案为native-reference-plan.json；reference-result.json记录引擎指纹与文件哈希。

默认普通方案已由独立操作者按文档完成prepare→preview→render→verify，并通过基础设计检查：普通版自然阅读顺序，成品完整卡片与统一层级。同一引擎用于GUI。旧截图动画与旧说明已移到工具包外历史输出，不随包分发。

使用AGENT_START.md与docs/原生视频场景协议.md，先准备真实内容、看实际MC预览，再导出和检查成片。
