# 鱼丸创作工具箱 · MVP 0.1

**第一次接手的 Agent：请先读 [AGENT_START.md](AGENT_START.md)。** 包内提供完整任务背景、示例课件/视频、方案格式，以及导入 → 预览 → 视频导出 → 校验的统一命令。只需本包与用户原始 PPT，无需历史聊天。运行环境与能力要求见该入口。

用于本地制作医护 PPT 图文笔记和上下对比组件重组视频。

**图文笔记可独立使用；PPT组件重组视频明确配合 Codex 或 WorkBuddy。** AI负责读课件、核内容、设计独立普通版与原生成品，用户不手写方案；工具负责源绑定、真实预览、聚合渲染与交付。辅助OCR不是自动设计完成，不需要购买或上传到新的第三方服务。

## 开始试用

- Mac：双击“启动Mac.command”，或打开同目录的“鱼丸创作工具箱.app”。
- Windows：解压到普通文件夹，双击“启动Windows.cmd”。首次安装需要联网；后续内容处理在本机完成。
- 首次启动准备 Python 处理组件、视频组件与浏览器。Mac 需有 Python 3.11+（或 uv）和 Node.js；Windows 启动脚本可通过系统 winget 安装 Python 和 Node.js。
- PPT 导入需要 LibreOffice。Windows 可双击“安装PPT支持Windows.cmd”；没安装时可先导入 PDF / PNG / JPG。
- 当前 GUI 在本机浏览器打开，不是云端网站。启动后由独立后台服务运行，关闭启动窗口不再停止后台。Mac 服务异常退出会自动重启；若系统 LaunchAgent 无法启动，入口会自动改用独立后台守护进程，并保存诊断日志。电脑重启后再次双击启动入口即可。
- 当前 Mac 已实测，Windows 提供同一套源代码与启动入口，但未在真实 Windows 环境完成验收。不是已签名的双平台安装成品。

## 图文笔记

1. 导入 PPT、PDF 或多张图片，点击页图检查。
2. 从 11 个已注册模板中选择一个，填写封面页号、每张内容图的页号组合；可按顺序自动填写后调整。
3. 分别填写发布标题、图内短句、副标题和话题；有奖项的模板填写已确认奖项。
4. 生成预览，查看实际图片与检查结果，下载 PNG / JPG / 文案素材包。

内容默认无正文。标题不超过 20 字。完整新笔记建议封面加至少四张内容图，8–10 个相关话题；检查通过不等于已发布。参考背景模板保留本地样稿用途说明，未代为取得第三方素材公开分发授权。17 号待确认模板未放入默认可用列表。

## 对比视频：AI协作主流程

1. 把工具包和原始课件交给Codex或WorkBuddy，要求其完整阅读 [AGENT_START.md](AGENT_START.md)。
2. AI读全册和选页原图，动态制定独立简陋版、原生成品与同节点映射；用户不手写JSON。复杂页使用scene+node.before，不把成品卡片去边框/拆散作普通版。
3. GUI导入同一原始课件，点击“导入AI方案”；工具校验原件指纹并绑定当前页。辅助识别仅供AI准备材料，不是已完成的设计。
4. 查看实际Motion Canvas首尾与运动预览，确认内容、表格、照片、流程方向及排版，再逐页确认制作。普通端固定，下方同批图文聚合、整组穿行并回弹落位。
5. 本地导出1080×1440/30fps MP4、普通版PPT、实际两版图片、可编辑方案和ZIP。技术校验不代替读图与视觉验收。

普通PPT字体检查使用本任务fontconfig并看实际渲染，不能只提取文字；外部编辑器依赖可用Noto CJK字体，未做所有Office/平台保证。可附已检查PDF供直接查看，方法见[普通PPT字体与检查](docs/普通PPT字体与检查.md)。

格式与图片素材对应见 [AI视频方案协议](docs/AI视频方案协议.md)，完整可运行虚构例子见 `examples/agent-video/ai-native-plan.json`。原文与数据不得擅改，词语不拆断、单字不孤行；无法读清时如实记录具体缺口，不拿整页截图充数。用户素材不会因此上传第三方或发布。

完整v7固定三段模板、轻量卡片模板保留兼容；它们有既定结构，不是任意PPT自动美化器。图文笔记和图片处理仍可独立使用，本工具未内置AI聊天，AI通过本地文件/统一接口协作。

## 保存与AI方案移交

“保存作品”保存本地设置、导入页和导出记录，重新制作不覆盖旧版。“导出方案”与“导入方案”支持继续编辑；AI的Agent plan.json可直接通过视频区导入。方案不携带原始PPT页，换电脑先导入同一原件；显式scene和node.before保留，旧确认清空，修改后须重新预览。

数据保存在用户Documents下的“鱼丸创作工具箱”，与软件目录分离，不自动上传、发布或发送给他人。

## 当前范围

本版封装常用笔记制作与 v7 视频制作链路，不宣称复刻原玩赚工具箱全部 41 项功能。未包含 Word 系列、任意 PPT 原生动画导出、任意自由画布编辑、跨平台签名安装器或自动平台发布。

对外学员安装体验仍需验证，尤其 Windows 首次环境安装、LibreOffice 字体与中文路径。本机试用通过不代表其他电脑具备相同依赖。engine/ 是现有引擎的独立副本，使用便携字体；不修改原项目或历史成片。

### 图内文字编辑（2026-10-17）

新生成的笔记预览可点击进入编辑：选中文字后拖动位置、双击修改内容，通过字号输入或右下角手柄缩放；支持撤销与还原。保存会产生一个新版本，并更新该版本的 PNG、已有 JPG 和素材包，不覆盖旧版或其他图片。模板内相连的主题与奖项目前作为一个组合移动，内容分两行修改。课件截图内的文字仍是原图，需要在源课件中修改。旧预览需要重新生成一次，才能保留文字层。素材包内的 `.layers` 文件夹保存背景、文字层和编辑数据。

视频页与Agent共用Motion Canvas原生渲染入口。新任务按上方AI协作主流程和AGENT_START执行；手动框选/微调仅为辅助，不是让用户逐页手写方案。

### 图片处理（2026-10-18）

主界面点击“图片处理”，或打开 `/images.html`。支持 JPEG/PNG 单张与批量、八组效果、完整分辨率预览和长按原图、稳定 seed、重置、预设、清信息验证、取消与独立批导出。无需 AI。兼容模式 OFF 也不保留源信息，透明度会丢失、方向不会自动转正；不保证平台查重结果。原文件只读，中间文件写入导入隔离副本。使用说明、CLI及适配差异见 [图片处理](docs/图片处理.md)，验收范围见 [图片处理验收](docs/图片处理验收.md)。

Mac 启动排查：应用数据目录中的 `startup.log`、`service.stdout.log`、`service.stderr.log` 保留启动与处理日志；`launchd-fallback.json` 保存 LaunchAgent 失败快照。回退守护进程通过文件锁防重复，重复双击会复用已运行服务。源码路径移动后请先退出旧服务再从新目录启动；本次仅修复当前目录入口，未创建系统开机启动项。

笔记导出默认自动清除图片元信息（含图内编辑另存版本、PNG/JPG 和素材包内图层图片），使用图片去重模块的清理与验证；保留画面像素与透明度，无需手动勾选。仅影响新导出，旧文件保留。
